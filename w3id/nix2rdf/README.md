# /nix2rdf

Permanent identifiers for the RDF vocabulary used by
[nix2rdf](https://github.com/samrose/nix2rdf), a tool that turns Nix build
artifacts (derivations, outputs, sources, flakes, nixpkgs revisions, NixOS
configurations, OCI images) into a content-addressed RDF dataset:

- `https://w3id.org/nix2rdf/ns#` — the core vocabulary
- `https://w3id.org/nix2rdf/k8s#` — the companion Kubernetes vocabulary
- `https://w3id.org/nix2rdf/id/` — the instance namespace
- `https://w3id.org/nix2rdf/ontology/<semver>` — versioned ontology documents

Target: https://samrose.github.io/nix2rdf-ontology/ (GitHub Pages, served from
the `nix2rdf-ontology` repository, generated by nix2rdf's build).
