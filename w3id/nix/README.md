# /nix

Permanent identifiers for the **Nix vocabulary** used by
[nix2rdf](https://github.com/samrose/nix2rdf): an RDF vocabulary for Nix
derivations, outputs, sources, flakes, nixpkgs revisions, NixOS
configurations and OCI images (`https://w3id.org/nix/ns#`), a companion
vocabulary for Kubernetes deployments (`https://w3id.org/nix/k8s#`), the
instance namespace (`https://w3id.org/nix/id/`) and versioned ontology
documents (`https://w3id.org/nix/ontology/<semver>`).

Target: https://samrose.github.io/nix-ontology/ (GitHub Pages, served from the
`nix-ontology` repository, generated by nix2rdf's build).
